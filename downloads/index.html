Step 2

Connect to a backend

Workspace needs an EHR server to store and sync your clinic's data. Use our free cloud (the easy path) or self-host the open source server yourself.

Recommended

Claim a free cloud account

We host the EHR server for you. Sign up, sign in from Workspace, and start charting in minutes — no servers, no IT contract.

Self-host the EHR server

Have your own IT? Run the open source Ciyex EHR server on your own infrastructure. Workspace will connect to it the same way it connects to our cloud.

  • Full data sovereignty · AGPL-3.0 licensed
  • One command Docker stack with PostgreSQL
  • Kubernetes, Helm & bare-metal supported
docker pull ciyexorg/ciyex:latest
